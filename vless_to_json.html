تبدیل گروهی VLESS به JSON

هر لینک vless:// را در یک خط وارد کنید. ابزار برای هر لینک یک آبجکت با ساختار تمپلیت شما می‌سازد و خروجی را به‌صورت آرایه JSON می‌دهد. پردازش کاملاً داخل مرورگر انجام می‌شود و چیزی آپلود نمی‌شود.

آمادهٔ تبدیل.
نکته: این نسخه پارامترهای رایج VLESS شامل UUID، آدرس، پورت، نوع انتقال، TLS، SNI، fingerprint، Host و Path را می‌خواند. برای لینک‌های غیر WS نیز مقدار network از لینک گرفته می‌شود؛ ساختار تنظیمات اختصاصی هر پروتکل ممکن است به ویرایش جداگانه نیاز داشته باشد.
